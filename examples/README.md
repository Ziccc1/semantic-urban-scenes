本目录收录可共享的小样例。按方法与样例编号组织，样例根目录放 manifest.json。其他样例在此登记获取方式。

- Scene-Scale Diffusion **主样例 `carla-seed-44`**。包含 13,490 个占据体素，覆盖 10 个语义类别。 [样例清单](scene-scale-diffusion/carla-seed-44/manifest.json)
- Scene-Scale Diffusion **对照样例 `carla-seed-7392`**。包含 15,679 个占据体素，类别覆盖相同，道路边缘更破碎。 [样例清单](scene-scale-diffusion/carla-seed-7392/manifest.json)

- PDD **主样例 `carlasc-v3-20261015`**。提供同一街区的粗、中、细三尺度，细尺度采用 V3。[样例清单](pdd/carlasc-v3-20261015/manifest.json)
